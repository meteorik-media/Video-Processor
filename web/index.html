Origen

Archivos sueltos o carpetas (se recorren con subcarpetas). Los originales nunca se tocan.

Salida

Se crea si no existe. Si ya hay un manifest.json, lo ya procesado se salta.

Preset

Ajustes (pisan el preset)

Vacío = lo que diga el preset. «Esperar» salta archivos modificados hace menos de N segundos (por si aún se graban).

Trozos y escenas

Trocear: 30m, 90s, 1h… (vacío = un solo archivo). Escenas: cambios candidatos en markers.csv (0.3 es un buen punto de partida).

Vigilar carpeta

Con «Vigilar» el proceso queda activo y procesa lo nuevo en cada pasada. Para algo que sobreviva al cierre de esta ventana usa un schedule (ver README).
